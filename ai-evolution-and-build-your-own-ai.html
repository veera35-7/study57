Attention in Plain Terms

QueryWhat am I looking for?
KeyWhat is available?
ValueWhat gets passed forward?
Attention ScoreQuery–Key similarity.
Attention WeightsNormalized scores.
Context RepresentationWeighted blend of values.

Simplified example: In "The cat sat on the mat," when the model processes "sat," self-attention lets it weigh "cat" and "mat" more heavily than distant words — capturing meaning without recurrent state.

11 — REASONING AI

Reasoning AI

Pattern CompletionPredicting likely continuations from training patterns.
Structured ReasoningDeliberate multi-step derivation toward a conclusion.

Capabilities

DeliberationTaking more compute before answering.
PlanningSequencing steps toward a goal.
DecompositionBreaking problems into sub-problems.
VerificationChecking intermediate results.
Self-CheckingReviewing own output for errors.
Tool-Assisted ReasoningUsing calculators, search, or code.
Long-Horizon TasksWork spanning many steps or sessions.

Key distinction: Reasoning can be a model capability (produced by the model itself) or an application-level workflow (orchestrated by the surrounding system). Many production systems combine both.

35 — BUILD LEVELS

Build Your Own AI — Five Levels

LEVEL 1 — AI API Application

Use a hosted model API to build an application.

  • Prompt design, structured output
  • Basic evaluation and guardrails
  • Lowest infrastructure footprint

LEVEL 2 — RAG + Tools

Add retrieval and tool use to your application.

  • Document ingestion and embeddings
  • Vector DB and access control
  • Tool calling and function calling

LEVEL 3 — AI Agent

Build agents that plan, act, and verify.

  • Planning and memory
  • Sandboxing and approvals
  • Observability and guardrails

LEVEL 4 — Fine-Tuned Open Model

Adapt an open-weight model to your domain.

  • Data curation and evaluation
  • LoRA / QLoRA or full fine-tune
  • Serving and versioning

LEVEL 5 — Own Foundation Model

Pretrain a large model from scratch.

  • Massive data pipelines
  • Distributed training clusters
  • Safety, governance, serving at scale

Specific cost, data, and compute figures vary widely by scale, architecture, and provider. This page intentionally avoids fabricated estimates.

FINAL

Where to Go Next

AI is a layered discipline. Start where you are, build the layer above, and keep evaluating as you go.

If you are newStart with Level 1 — an AI API application — and get one working end to end.
If you have shipped an appAdd RAG, then tools, then agents. Measure every step.
If you need domain accuracyConsider fine-tuning or adapters after establishing a strong baseline.
If you want local controlTry open-weight models with a local runtime and quantization.
If you care about productionInvest in evaluation, observability, security, and governance.
If you are researchingDistributed training, architectures, and evaluation methods are open frontiers.
